# Template para Geração de Flashcards — MedClass UNR

## Instruções de uso

1. Copie este documento completo e envie para uma IA (ChatGPT, Gemini, etc.)
2. Peça para ela gerar flashcards no formato JSON descrito abaixo
3. A IA deve preencher todos os campos usando as listas de valores válidos fornecidas
4. Salve o JSON gerado em um arquivo (ex: `flashcards-import.json`)
5. Envie esse arquivo para o Claude junto com as instruções de importação

---

## Formato do JSON

O arquivo final deve ser um array de decks. Cada deck contém um array de cards.

```json
[
  {
    "titulo": "Anatomia do Sistema Cardiovascular",
    "ano": "ano1",
    "materia": "crescimento_desenvolvimento",
    "parcial": "parcial1",
    "disciplina_base": "anatomia",
    "descricao": "Principais estruturas do coração e grandes vasos",
    "tags": ["coracao", "vasos", "anatomia-cardiovascular"],
    "ordem": 1,
    "cards": [
      {
        "frente": "Quantas camadas (túnicas) formam a parede do coração?",
        "verso": "Três camadas: epicárdio (externa), miocárdio (média) e endocárdio (interna).",
        "fontes": ["Moore, Anatomia Orientada para a Clínica, 8ª ed., Cap. 1"]
      }
    ]
  }
]
```

---

## Estrutura dos Campos

### Deck

| Campo | Obrigatório | Descrição |
|---|---|---|
| `titulo` | Sim | Nome do deck (ex: "Anatomia do Sistema Cardiovascular") |
| `ano` | Sim | Chave canônica do ano (ver tabela ANOS) |
| `materia` | Sim | Chave canônica da matéria (ver tabela MATÉRIAS POR ANO) |
| `parcial` | Sim | `"parcial1"` ou `"parcial2"` |
| `disciplina_base` | Não | Chave canônica (ver DISCIPLINAS BASE) ou `null` |
| `descricao` | Não | Texto descritivo do deck |
| `tags` | Sim | Array de strings em **snake_case** (ex: `["coracao", "anatomia-cardiovascular"]`) |
| `ordem` | Sim | Número inteiro para ordenação (1, 2, 3...) |
| `cards` | Sim | Array de objetos card |

### Card

| Campo | Obrigatório | Descrição |
|---|---|---|
| `frente` | Sim | Pergunta ou termo (frente do flashcard) |
| `verso` | Sim | Resposta ou definição (verso do flashcard) |
| `fontes` | Não | Array de strings com referências bibliográficas |

## Regras para Tags

- Use **snake_case** (ex: `"reacoes-adversas"`, `"sistema-renina-angiotensina"`)
- Prefixos úteis por disciplina base:
  - anatomia: `"anatomia-"` (ex: `"anatomia-cardiovascular"`)
  - fisiologia: `"fisiologia-"` (ex: `"fisiologia-renal"`)
  - farmacologia_base: `"farmaco-"` (ex: `"farmaco-bloqueadores"`)
  - patologia: `"patologia-"` (ex: `"patologia-inflamacao"`)
- Para matérias clínicas (4º/5º ano), use o nome direto:
  - `"hipertensao"`, `"dm-tipo-2"`, `"apendicite"`, etc.
- Inclua sempre tags que ajudem na busca:
  - Sistema/órgão envolvido (ex: `"sistema-cardiovascular"`, `"rins"`)
  - Se aplicável, o nome da patologia (ex: `"insuficiencia-cardiaca"`)
  - Classe de fármaco (ex: `"iec"`, `"beta-bloqueadores"`)
- Máximo de 8 tags por deck

---

## Regras para o Conteúdo dos Cards

1. **Frente** deve ser uma pergunta direta ou termo a ser definido
2. **Verso** deve conter a resposta completa mas concisa
3. **Dificuldade** deve ser adequada ao ano da matéria:
   - 1º-2º ano: conceitos fundamentais, definições, estruturas
   - 3º ano: mecanismos de doença e defesa, fisiopatologia
   - 4º-5º ano: diagnóstico, tratamento, conduta clínica
4. **Quantidade ideal** de cards por deck: 8-15 cards
5. **Distribuição** ideal: criar múltiplos decks por matéria (não 1 deck gigante)
   - Ex: "Farmacologia Cardiovascular" e "Farmacologia do SNA" em vez de "Farmacologia"

## Prompt para Enviar à IA Geradora

Copie e cole este prompt:

```
Gere flashcards de medicina no formato JSON abaixo. Siga rigorosamente os valores válidos da grade curricular da UNR fornecidos.

[METADADOS DO USUÁRIO - PREENCHER ANTES DE ENVIAR]
- Ano alvo: [ex: ano1, ano2, ano3, ano4, ano5]
- Matéria(s): [ex: todas, ou lista específica]
- Parcial: [parcial1, parcial2, ou ambos]
- Quantidade de decks: [ex: 5]
- Tema geral: [ex: sistema cardiovascular, antibioticoterapia, etc.]

FORMATO JSON (cada deck deve ser um objeto no array principal):
[ré do formato JSON documentado acima]

LISTA COMPLETA DE VALORES VÁLIDOS:
[ré das tabelas ANOS, MATÉRIAS POR ANO, PARCIAIS, DISCIPLINAS BASE e REGRAS PARA TAGS documentadas acima]

REGRAS:
1. Cada deck deve ter 8-15 cards
2. Frente em forma de pergunta; verso com resposta completa e concisa
3. Conteúdo adequado ao ano (1º-2º: fundamentos; 3º: mecanismos; 4º-5º: clínica)
4. Tags em snake_case
5. Incluir fontes bibliográficas reais sempre que possível
6. Não repetir conteúdo entre decks
```
