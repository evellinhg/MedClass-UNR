==================================================================
MEDCLASS UNR — TEMPLATE PARA CADASTRO DE QUESTÕES
==================================================================
Instruções de uso:
- Copie o bloco "QUESTÃO #N" abaixo para cada questão nova.
- Preencha todos os campos entre [colchetes].
- Não apague as linhas de cabeçalho (ANO / MATÉRIA / PARCIAL / etc.),
  elas são o que o Claude usa para separar e converter as questões.
- Pode colocar quantas questões quiser no mesmo arquivo, uma após a
  outra, numerando sequencialmente (QUESTÃO #1, QUESTÃO #2, ...).
- Alternativas podem ser A/B/C/D ou A/B/C/D/E — não precisa ser
  sempre 4.
- MATÉRIA deve ser uma das opções da lista "MATÉRIAS VÁLIDAS POR
  ANO" no final deste documento — é a mesma lista do dropdown no
  painel admin, então usar esses nomes exatos evita retrabalho.
- Quando terminar, envie o arquivo (.txt ou .docx) para o Claude
  converter em JSON.
==================================================================
