==================================================================
MEDCLASS UNR — TEMPLATE PARA CADASTRO DE QUESTÕES
==================================================================
Instruções de uso:
- Copie o bloco "QUESTÃO #N" abaixo para cada questão nova.
- Preencha todos os campos entre [colchetes].
- Não apague as linhas de cabeçalho (ANO / MATÉRIA / PARCIAL / etc.),
  elas são o que o Claude usa para separar e converter as questões.
- Pode colocar quantas questões quiser no mesmo arquivo, uma após a
  outra, numerando sequencialmente (QUESTÃO #1, QUESTÃO #2, ...).
- Alternativas podem ser A/B/C/D ou A/B/C/D/E — não precisa ser
  sempre 4.
- MATÉRIA deve ser uma das opções da lista "MATÉRIAS VÁLIDAS POR
  ANO" no final deste documento — é a mesma lista do dropdown no
  painel admin, então usar esses nomes exatos evita retrabalho.
- DISCIPLINA BASE é opcional (pode deixar em branco). Se souber a
  ciência básica por trás da questão (Anatomia, Fisiologia etc.),
  preencha com um dos nomes da lista "DISCIPLINAS BASE VÁLIDAS" no
  final do documento — isso é o que alimenta o detalhamento por
  disciplina no painel de Desempenho do aluno. Se deixar em branco,
  a questão fica sem essa classificação (pode ser preenchida depois).
- IDIOMA: ENUNCIADO e ALTERNATIVAS devem estar em ESPANHOL (é o
  idioma das questões na plataforma). O FEEDBACK de cada alternativa
  também deve estar em espanhol.
- FEEDBACK: nunca escreva só "Correcto." ou "Incorrecto." sem
  explicação. Toda alternativa — certa ou errada — precisa de uma
  explicação completa que ensine o porquê: para a correta, reforce o
  conceito; para as erradas, explique especificamente por que aquela
  alternativa está errada (não basta negar a afirmação, é preciso
  justificar com o raciocínio/conceito correto).
- Quando terminar, envie o arquivo (.txt ou .docx) para o Claude
  converter em JSON.
==================================================================
